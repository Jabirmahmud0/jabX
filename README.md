## 🚀 Overview

**JabX** is a high-performance, visually immersive portfolio built for the modern web. It showcases a blend of creative development, sophisticated 3D interactions, and AI-powered utilities, designed to provide a premium user experience.

Built with **Next.js 16.2** and **React 19**, this project implements state-of-the-art web technologies including **Three.js** for 3D graphics and **Tailwind CSS 4** for futuristic styling.

## ✨ Key Features

- 🎨 **Aurora UI Aesthetic**: Premium glassmorphism effects with deep background textures and vibrant gradients.
- 🧊 **3D Interactions**: Seamlessly integrated 3D elements powered by React Three Fiber and Drei.
- 📜 **Smooth Scroll**: Tactile scrolling experience using Lenis for refined navigability.
- ⚡ **Next.js App Router**: Optimized performance, SEO-friendly architecture, and advanced routing.
- 📧 **Direct Contact**: Integrated contact system via EmailJS for real-time lead generation.
- 📱 **Fully Responsive**: Optimized for every device, from high-end desktops to mobile screens.

## 🛠️ Tech Stack

### Core
- **Framework**: [Next.js 16.2+](https://nextjs.org/) (App Router)
- **Library**: [React 19](https://react.dev/)
- **Styling**: [Tailwind CSS 4](https://tailwindcss.com/)

### Experience & Motion
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **3D Runtime**: [React Three Fiber](https://r3f.docs.pmnd.rs/getting-started/introduction) & [Three.js](https://threejs.org/)
- **Smooth Scrolling**: [Lenis](https://lenis.darkroom.engineering/)

### Tools & Utilities
- **Icons**: [Lucide React](https://lucide.dev/)
- **Analytics**: [Google Analytics 4](https://analytics.google.com/)
- **Contact Service**: [EmailJS](https://www.emailjs.com/)

## ⚙️ Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (Latest LTS)
- NPM or PNPM

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Jabirmahmud0/jabX.git
   cd jabX
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Configure Environment Variables:**
   Create a `.env.local` file in the root directory and add your credentials (see `.env.example` for reference):
   ```env
   NEXT_PUBLIC_EMAILJS_SERVICE_ID=your_id
   NEXT_PUBLIC_EMAILJS_TEMPLATE_ID=your_id
   NEXT_PUBLIC_EMAILJS_PUBLIC_KEY=your_key
   NEXT_PUBLIC_GA_ID=your_ga_id
   ```

4. **Run Development Server:**
   ```bash
   npm run dev
   ```
   Visit `http://localhost:3000` to see the result.

## 🌐 Deployment

This project is optimized for deployment on the [Vercel Platform](https://vercel.com/new?utm_source=github&utm_medium=readme&utm_campaign=next-example).

1.  Push your code to a GitHub repository.
2.  Import the repository into Vercel.
3.  Add the Environment Variables in the Vercel Dashboard.
4.  Deploy!
